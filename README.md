# Knee Comeback

A criteria-based home rehab tracker for both knees (16 weeks plus a maintenance phase), installable on iPad and usable offline.

- **Today:** daily check-in (pain, swelling, full straightening, next-morning response), a coach card with suggestions (add weight, lighter week, missed session, checks due), set ticking with an automatic rest timer, weight logging, Express sessions and a full-screen guided workout mode
- **Plan:** 6 phases (Activate, Build, Load, Impact, Return, Maintain), jump blocks with landing counts, workout A/B, lighter weeks, pain rules, daily-life advice and a guide to getting back on the bike
- **Exercises:** 55 exercises with why, setup, steps, cues, mistakes and easier/harder versions
- **Progress:** pain trend, consistency, program calendar, phase criteria, walk–run program, drop landing ladder, confidence check, strength and hop tests
- **Doctor report:** a 4- or 8-week summary to share with your orthopedist, plus questions to ask
- **Settings:** pause the plan for travel, illness or a flare-up; export the weekly schedule to Calendar; backup and import

Install: open the GitHub Pages address in Safari, tap Share, then Add to Home Screen. Data stays on the device; use Settings → Export backup now and then.

General guidance only. Follow your orthopedist's and physiotherapist's advice.
