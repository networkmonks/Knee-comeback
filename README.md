# Knee Comeback

A 16-week, criteria-based home rehab tracker for both knees, installable on iPad and usable offline.

- **Today:** daily check-in (pain, swelling, full straightening, next-morning response), set ticking with an automatic rest timer, weight logging and exercise flags
- **Plan:** 5 phases (Activate, Build, Load, Impact, Return), weekly rhythm, pain rules and a guide to getting back on the bike
- **Exercises:** 53 exercises with why, setup, steps, cues, mistakes and easier/harder versions
- **Progress:** pain trend, consistency, program calendar, phase criteria, walk–run program, drop landing ladder and strength/hop tests

Install: open the GitHub Pages address in Safari, tap Share, then Add to Home Screen. Data stays on the device; use Settings → Export backup now and then.

General guidance only. Follow your orthopedist's and physiotherapist's advice.
